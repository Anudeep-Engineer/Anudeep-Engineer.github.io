# Anudeep A · AI/ML Engineer Portfolio

Live at **https://anudeep-engineer.github.io**

A single-page animated portfolio: space background, LangGraph agent diagram, in-browser RAG demo ("Ask my portfolio"), experience timeline, skills and contact.

Static site, no build step:
- `index.html`: the whole site (styles, scripts and portrait embedded)
- `Anudeep_AI_ML_Engineer_Resume.pdf`: served by the Download resume buttons
- `og.jpg`: preview image shown when the link is shared

## Deploy on GitHub Pages
1. Name the repository `Anudeep-Engineer.github.io` and make it public.
2. Upload these files to the root of the `main` branch.
3. Settings > Pages > Build and deployment: Source **Deploy from a branch**, Branch **main**, folder **/ (root)**, Save.

## Update the resume
Replace the PDF with a new file of exactly the same name and commit.
